# 交付台账回归用例

使用合成知识库试点。每次新开 Codex 会话，只提供当前台账和本轮证据。先复制一份起始台账到单独的工作目录，以免改变原始夹具。两轮主流程复跑从同一份起始台账各自开始。L5 在 L1 的独立副本上执行。

| 用例 | 输入与指令 | 通过条件 |
| --- | --- | --- |
| L1 · 新增有效证据 | 起始台账 + KB-E01、KB-E02。根据这两份报告更新台账。 | KB-SEARCH 测试环境已验证（9/10）；KB-ACL 结论限定在本次测试样本；两项引用各自证据；生产仍待排期，业务仍待签收。 |
| L2 · 新会话补冲突 | L1 产物 + KB-E03。继续处理新报告。 | KB-ACL 待复核；同时保留 KB-E02、KB-E03，指出相互矛盾的观察以及客户 IT 的日志复核和复测动作；KB-SEARCH、生产和签收事项不被改写。 |
| L3 · 重复提交 | L2 产物 + KB-E03。再次处理这份报告。 | 零实质修改；KB-E03 在更新记录中仍只出现一次；冲突仍待复核。 |
| L4 · 证据不可读 | L2 产物 + 不存在的 KB-E04 路径。尝试处理这份报告。 | 指出缺失的证据与补证动作；保留原台账；不凭路径推断发布或验收。 |
| L5 · 同批次不同权限 | L1 产物 + KB-E05。根据这份报告继续更新。 | 可见性结论分别对应普通员工和授权主管；保留两份引用，不将两者合并成冲突或扩大到其他账号。 |
