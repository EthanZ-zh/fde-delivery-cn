# v0.2 台账行为评测

运行日期为 2026-11-25（北京时间）。在 Windows Codex 桌面宿主中用独立任务会话执行 [台账回归用例](ledger-cases.md)。每次只把工作目录与相关文件路径交给会话。写入阶段直接读取和更新本地台账副本，根仓库中的合成夹具保持原样。

| 用例 | 通过次数 | 观察到的行为 |
| --- | --- | --- |
| L1 · 新增有效证据 | 2/2 | 两轮检索都保留测试版本、阈值和 9/10 的证据，权限结论限于本次普通员工样本。发布和签收行保持原样。 |
| L2 · 新会话补冲突 | 2/2 | 仅更新 KB-ACL 行并追加一条记录。两个来源及相反观察同时保留，客户 IT 负责核对 SYN-R17 网关日志并按原条件复测。其余事项与上轮逐行一致。 |
| L3 · 重复提交 | 2/2 | 两轮再次提交 KB-E03 后，台账与 L2 的 SHA-256 分别完全一致，冲突历史仍各占一条。 |
| L4 · 证据不可读 | 1/1 | 直接读取发现 KB-E04 路径不存在，要求提交人补交原文件或提供实际路径。台账与 L2 快照逐字节一致。 |
| L5 · 同批次不同权限 | 1/1 | 同一查询按普通员工和授权主管分别记录，保留两份证据。两项观察在各自权限范围内成立。 |
| **合计** | **8/8** | 各次运行保留待排期和待签收状态，报告冲突时附责任人与复测动作。 |

L1 至 L3 分为两轮，各轮使用独立文件副本。L4 使用一份 L2 副本，L5 使用一份 L1 副本。每项任务单独启动；按实际文件、摘要和差异比对评分。Codex app-server 另确认新版 Skill 在仓库级可发现且启用。

评测采用合成材料，覆盖桌面宿主实际文件读写。v0.1 记录的 Windows CLI 只读沙箱限制未在本轮重测，客户实际部署和业务效果待验证。 [v0.1 运行边界](results.md#运行边界)
