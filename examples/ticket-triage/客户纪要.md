# 远舟制造服务台试点纪要

本案例的组织、人员角色、工单及指标均为合成素材。

- 服务台值班主管说，人工判断工单队列耗时，想先优化办公网故障的分流。
- 试点只覆盖服务台一个队列。建议由值班主管逐条确认；服务不可用或类别未识别时，维持原有人工处理流程。
- 业务验收人是服务台负责人。客户 IT 管理既有工单系统，值班主管负责一线回退，运维组接手告警。
- 演示对象是工单 DEMO-1042 和 DEMO-1043。预期对已识别的网络故障推荐「IT 支持」。
- 业务指标拟采用人工分流耗时和改派率。客户尚未提供历史样本、基线或验收阈值。
- 实际工单系统位于客户内网。外部模型和互联网连接尚未获准，测试环境账号和接口说明待客户 IT 提供。
